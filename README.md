# Spootfind

AI-driven product sourcing platform for global dropshippers.

**Last synced:** 2026-07-09

## Features
- Trending products from TikTok & Amazon
- Multi-language support (10 languages)  
- Procurement cost calculator
- Real-time market insights

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- next-intl (i18n)
- Vercel deployment
