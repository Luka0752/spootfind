# OG Image for Spootfind

## Required Specifications
- **Dimensions:** 1200 × 630 px (Twitter/OG standard)
- **Format:** PNG (or JPG/JPEG if preferred)
- **File name:** og-image.png (replace/rename as needed)
- **Location:** public/og-image.png

## Recommended Tools
- **Figma** (recommended for design control)
- **Canva** (quick and easy, free tier available)
- **Adobe Express** (free, browser-based)

## Design Recommendations

### Layout
- Left side: Spootfind logo or icon (large)
- Right side: Bold headline text
- Dark background (#0D0F1A or similar) matching site aesthetic

### Suggested Text / Copy
Headline options (pick one):
- "Curated Viral Products & Sourcing Insights"
- "Find Your Next Bestseller"
- "Trending Products · TikTok to Amazon"

Subline:
- "spootfind.com" or "#1 Trending Product Discovery"

### Color Palette (match site)
- Background: #0D0F1A (dark navy)
- Primary accent: #60A5FA (brand blue)
- Text: #FFFFFF / #E5E7EB

### Brand Elements
- Logo: /logo.png
- Favicon: /favicon.ico

## Quick Canva Template
Search Canva for "Facebook Post" template (1200×630), then customize with:
1. Dark background
2. Logo centered or left
3. Headline text in white/bold
4. Brand blue accent elements

## Notes
- og:image.png in /public will be served at https://spootfind.com/og-image.png
- Update og:image path in app/[locale]/seo.ts if using different filename
- Test with: https://socialsharepreview.com/ or Twitter Card Validator
