# Spootfind 内容策略文档

## 一、目标市场分析

| 市场 | 核心特征 | 用户习惯 | 优先品类 |
|------|----------|----------|----------|
| 美国 | 高消费力，偏爱科技/家居产品，注重性价比 | 日均社交媒体使用3.5h，偏好TikTok/Instagram | 电子产品、家居用品、健身器材 |
| 欧洲 | 注重环保、可持续性，偏好本地/合规产品 | 重视隐私，对产品认证（CE/ROHS）敏感 | 环保家居、户外用品、美妆个护 |
| 澳洲 | 户外生活方式盛行，偏爱运动/露营产品 | 社交媒体使用率高，KOL影响力大 | 户外装备、健身器材、宠物用品 |
| 加拿大 | 多元文化，偏好性价比高的跨境产品 | 冬季产品需求旺盛，注重物流时效 | 冬季服饰、家居保暖、电子产品 |

## 二、SEO 关键词策略

### 通用核心词
`product trends`, `trending products`, `top rated products`, `best selling items`, `global product rankings`

### 按品类分组
#### 电子产品
- 核心词：`trending electronics`, `best selling gadgets`, `top tech products`
- 长尾词：`noise cancelling earbuds trending 2026`, `budget wireless earbuds top rated`, `smart home devices trending now`

- 核心词：`trending home goods`, `best selling home decor`, `top kitchen gadgets`
- 长尾词：`sustainable home products trending`, `space saving kitchen gadgets 2026`, `affordable home decor trending`

#### 健身器材
- 核心词：`trending fitness gear`, `best selling workout equipment`, `top home gym products`
- 长尾词：`compact home gym equipment trending`, `budget fitness gear for apartments`, `yoga mats trending 2026`

- 核心词：`trending beauty products`, `best selling skincare`, `top makeup products`
- 长尾词：`cruelty free makeup trending`, `affordable skincare routine products`, `korean beauty trends 2026`

## 四、社媒发布计划

### 平台分配
- **TikTok/Instagram Reels**：短视频展示产品使用场景，每周3条
- **Twitter/X**：实时趋势更新，每日2条
- **LinkedIn**：行业洞察/商家合作内容，每周1条
- **Pinterest**：产品合集图板，每周2个主题板

### 周度发布节奏
| 星期 | TikTok/Reels | Twitter/X | LinkedIn/Pinterest |
|------|--------------|-----------|---------------------|
| 周一 | 本周趋势产品Top3 | 周度趋势报告摘要 | - |
| 周二 | 产品实测短视频 | 用户好评截图分享 | - |
| 周三 | - | 品类趋势更新（如电子/家居） | LinkedIn: 行业趋势洞察 |
| 周四 | 开箱短视频 | 限时优惠提醒 | Pinterest: 主题产品合集 |
| 周五 | 周末好物推荐 | 周末购物指南 | - |
| 周六 | - | 用户UGC内容转发 | - |
| 周日 | 下周预告短视频 | 周度热门回顾 | - |

### 月度活动
- 每月1日：发布上月趋势报告长图
- 每月15日：限时投票活动（用户选下月重点品类）
- 每月最后一日：月度爆款产品颁奖
